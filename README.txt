# श्री विष्णुबुवा वावंजेकर — भजन व अभंग वेबसाइट

## Audio जोडण्याची पद्धत
`audio` फोल्डरमध्ये तुमच्या स्वतःच्या/वापरण्याची परवानगी असलेल्या MP3 फाईल्स ठेवा:

1. `vadilanche-daivat.mp3`
2. `tochi-varkari-pandharicha.mp3`
3. `ganraya-lavkar-yei.mp3`

नंतर `index.html` उघडल्यावर प्रत्येक कार्डमध्ये audio player दिसेल.

टीप: YouTube URL थेट HTML `<audio>` player मध्ये audio-only म्हणून वापरता येत नाही. त्यामुळे website वर audio ऐकवण्यासाठी स्वतंत्र MP3 फाईल आवश्यक आहे.
